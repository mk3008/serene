# Serene 0.2.0

Serene 0.2.0 fixes Windows absolute-path handling in the source audit.

### Audit

- `serene-audit` now recognizes Serene construction when an explicit Windows
  absolute path uses backslashes.
- Audit output retains the caller-supplied path spelling, including backslashes.
- Relative paths and absolute paths using forward slashes retain their existing
  behavior across supported platforms.

### Install

```sh
npm install github:mk3008/serene#v0.2.0
```
