# Serene 0.3.0

Serene 0.3.0 adds bounded native QueryConfig recognition to the audit while keeping Serene native SQL / native driver first.

### Audit

- `serene-audit` recognizes a proven Serene `BoundSql` passed directly as the sole argument of a `query` candidate.
- A narrow inline `{ text: q.text, values: q.values }` form is also recognized when both fields retain proven Serene provenance.
- Aliased or mutable config objects, wrappers, factories, unknown fields, extra arguments and other unresolved shapes remain review-required.
- Source and diff filters stay conservative: QueryConfig calls remain visible even when the audit classifies their construction as ordinary.

### ORM coexistence

- README documents that Serene can coexist with an ORM only when the ORM exposes a transparent parameterized raw-SQL path that preserves SQL text and bound values.
- No ORM-specific adapters, escaping rules or query-language compatibility layers are added.
