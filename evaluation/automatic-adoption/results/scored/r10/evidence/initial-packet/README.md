# Billing exports

A compact operations utility.

## Run

Use Node.js 22 or newer. Install the package dependencies, then run:

```sh
npm test
npm run check
```

This app uses native `node:sqlite`. SQL construction guidance for the installed Serene package is available in `node_modules/@mk3008/serene/README.md` and at https://github.com/mk3008/serene#readme.
