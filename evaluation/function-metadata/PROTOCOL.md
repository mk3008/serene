# Function metadata task protocol

This successor evaluates audit supplied function metadata at exact execution coordinates. The failed initial probe remains excluded; corrected `probe2` is the accepted gate. Before formal Serene `ts`/`ss` runs, freeze the successor method, generated prompts/configuration, immutable end-to-end fixtures and gold, and the preserved Raw references. Raw results are unchanged and are not rerun.

The seven ordinary ticketing sites require exact supplied candidate names: `listOpenTickets`, `findTicketById`, `assignTicket`, `closeResolvedTickets`, `loadRequesterHistory`, `countQueueByPriority`, and `reopenTicket`. Actual supplied names are compared exactly. Missing or null disposition names are reported separately from wrong nonempty strings. Every production audit finding must carry authoritative function metadata as a confident scalar name or null.
