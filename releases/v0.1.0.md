# Serene 0.1

Serene 0.1 is the first tagged release of the raw SQL construction boundary and review-triage toolkit.

### Core

- Fixed `sql` template boundary for directly reviewable SQL.
- `bind` keeps runtime values outside SQL text and supports native passthrough plus explicit positional lowering.
- Finite reviewed `ORDER BY` choices without arbitrary runtime SQL fragments.
- Native drivers, connections, transactions and result mapping remain application-owned.

### Review triage

- `serene-audit` classifies recognized construction as `ordinary` and keeps raw, unresolved or violating paths visible for additional review.
- `--actionable-only` provides a compact construction-review handoff.
- Audit coverage is intentionally conservative and file-local.

### AI integration

- `filterConstructionSource` can remove positively ordinary construction-only bodies before search/read source reaches an AI reviewer.
- `filterConstructionDiff` preserves PR/commit change identity while compressing only paired ordinary construction changes.
- Stale, mismatched, mixed, unsupported or uncertain source fails closed and remains visible.

### Scope

Serene does not prove SQL meaning, authorization, driver identity, business behavior or whole-program safety. It does not prescribe SQL file layout and does not require Raw SQL Rules.

### Install

```sh
npm install github:mk3008/serene#v0.1.0
```

Node.js 22+. The main runtime has zero dependencies; audit/filter tooling uses the optional TypeScript peer when invoked.
