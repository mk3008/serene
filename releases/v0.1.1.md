# Serene 0.1.1

Serene 0.1.1 is a packaging-only patch release that keeps the installed package as small as the product itself.

### Packaging

- Remove repository documentation from the installed package payload.
- Keep only the runtime/build output and Serene audit/filter tooling as package-managed files; npm still includes package metadata, README and license.
- No runtime, audit, filter, API, or review-classification behavior changes.

### Install

```sh
npm install github:mk3008/serene#v0.1.1
```

Node.js 22+. Full design, security, evaluation and integration documentation remains in the tagged GitHub repository rather than under `node_modules`.
